# 维度三：准正则模 — Π 作为振荡周期

> 黑洞合并后的"戒指"——振荡频率正比于 Π。Π 定义了振荡周期和阻尼时间。

---

## 准正则模（QNM）基础

两个黑洞合并后，**最终黑洞不是静止的** —— 它会振荡、释放引力辐射、逐渐趋于稳态。

这个过程叫 **ringdown**，可以用 **准正则模（QNM）** 描述。

---

## 数学描述

Kerr 度规的扰动方程（Teukolsky 方程）有复数频率解：

```
ω = ω_R + i ω_I
```

其中：
- **ω_R** = 实部 = 振荡频率（angular frequency）
- **ω_I** = 虚部 = 阻尼率（damping rate，负值）

**物理意义**：
- 振荡周期：T_osc = 2Π / ω_R
- 阻尼时间：τ = 2Π / |ω_I|
- 振幅衰减：A(t) ∝ exp(-|ω_I| t) · cos(ω_R t)

---

## Π 的角色

**Π 直接定义振荡周期和阻尼时间**：

```
T_osc = 2Π / ω_R   (Π 在分子)
τ = 2Π / |ω_I|     (Π 在分子)
```

**几何单位（G = c = 1）**：
```
ω_R ∝ Π / M
τ ∝ M / Π
```

所以：
- **质量越大** → ω_R 越小 → 振荡越慢
- **质量越小** → ω_R 越大 → 振荡越快

## 关键阈值

### 1. 基模（Fundamental Mode, n=0）

最慢阻尼的模（主导 ringdown 信号）：

| 模式 (l,m) | 实部 ω_R (c³/GM) | 虚部 ω_I (c³/GM) | 备注 |
|------------|---------------------|---------------------|------|
| (2,2) | 1.525 - 1.1566i | 最快增长模 | 主导 |
| (3,3) | 1.896 - 1.507i | 次快增长模 | 次主导 |
| (2,1) | 0.728 - 0.782i | 慢速模 | 弱信号 |

**Π 的角色**：
- 振荡频率 f = ω_R / (2Π) （单位：Hz，如果恢复物理单位）
- 所以 Π 把角频率 ω_R 转换成普通频率 f

### 2. 自旋依赖（a* = J/M²）

Kerr 黑洞的自旋参数 a* 显著影响 QNM 频率：

```
ω_R(a*) = ω_R(0) + Δω_R(a*)
|ω_I(a*)| = |ω_I(0)| + Δ|ω_I|(a*)
```

**极端 Kerr（a* = 1）**：
- ω_R 增大（旋转使振荡更快）
- |ω_I| 增大（阻尼更快）

**Π 的角色**：无论 a* 如何，ω_R 和 ω_I 都通过 2Π 转换成周期和阻尼时间。

### 3. 探测阈值（LIGO/Virgo 灵敏度）

LIGO 的应变灵敏度 ~ 10⁻²³ / √Hz。

**QNM 探测要求**：
- 信噪比 SNR > 8
- 至少一个完整周期（T_osc）在观测窗口内
- 阻尼时间 τ > T_osc（否则还没观测到就衰减完了）

**Π 的角色**：
- T_osc = 2Π/ω_R 必须 < 观测窗口（~ 0.1-1 秒）
- τ = 2Π/|ω_I| 必须 > T_osc（品质因子 Q = τ/T_osc > 1）

## 实际影响

### 1. 引力波探测（LIGO/Virgo/KAGRA）

**GW150914**（首次黑洞合并探测）：
- 最终质量 M ≈ 62 M☉
- 自旋 a* ≈ 0.67
- Ringdown 频率 f ≈ 235 Hz（对应 ω_R ≈ 2Π·235 ≈ 1477 rad/s）
- 阻尼时间 τ ≈ 3.5 ms

**Π 的角色**：
- 波形模型需要 Π 来转换 ω_R → f
- 参数估计（M, a*）需要精确计算 QNM 频率（涉及 Π）

### 2. 黑洞参数估计

从 ringdown 信号可以提取：
- **质量 M**：通过 ω_R ∝ 1/M
- **自旋 a***：通过 ω_R(a*), ω_I(a*)
- **模式衰减**：通过 τ = 2Π/|ω_I|

**Π 的角色**：
- 所有频率-质量转换都需要 Π
- 模式识别（哪个 (l,m) 模）需要 Π 来校准模板

### 3. 量子引力检验

**回声（Echoes）**：如果黑洞视界附近有量子修正（firewall、fuzzball、wormhole），QNM 谱会偏离广义相对论预言。

**探测**：
- 在 ringdown 信号中搜索"回声"（周期性反射）
- 偏差频率 ∝ Π/M（所以 Π 在阈值中）

**Π 的角色**：
- 回声周期 T_echo ∝ M ∝ 1/Π（如果 Π 变化，回声周期也变）
