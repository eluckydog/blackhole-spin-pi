# 维度二：Hawking 温度 — Π 作为压低因子

> Hawking 温度公式里 Π 在分母。Π 越大，温度越低，蒸发越慢。

---

## Schwarzschild 黑洞（无自旋）

Hawking 温度（无自旋黑洞）：

```
T = ħc³ / (8ΠGMk_B)
```

其中：
- ħ = 约化 Planck 常数
- c = 光速
- G = 引力常数
- M = 黑洞质量
- k_B = Boltzmann 常数
- **Π = 圆周率**

---

## Kerr 黑洞（有自旋）

对于旋转黑洞（Kerr 度规），Hawking 温度为：

```
T = ħc³ (r₊ - r₋) / [4Πk_B G M (r₊² + a²)]
```

其中：
- r₊ = M + √(M² - a²) （外视界）
- r₋ = M - √(M² - a²) （内视界）
- a = J/M （自旋参数）

---

## Π 的角色

**Π 在分母**。温度反比于 Π：

```
T ∝ 1 / Π
```

**物理意义**：
- Π 越大 → 温度越低 → 蒸发越慢
- Π 越小 → 温度越高 → 蒸发越快

**量纲分析**：
- 分子：ħc³ [能量·长度³/时间]
- 分母：G·M·k_B [能量·长度/温度]
- 所以 T ∝ (ħc³)/(GMk_B) ∝ 1/Π（因为 Π 来自几何面积 A = 4Πr²）

---

## 关键阈值

### 1. 小黑洞 vs. 大黑洞

| 质量 | 温度 | 蒸发时间 |
|------|------|----------|
| M ~ 10¹² kg（原初黑洞）| T ~ 10⁸ K（极热！）| τ ~ 13.8 Gyr（正在蒸发）|
| M = M☉（太阳质量）| T ~ 10⁻⁸ K（极冷）| τ ~ 10⁶⁷ 年（几乎永恒）|
| M ~ 10²³ kg（星系中心黑洞）| T ~ 10⁻¹⁸ K（接近 0K）| τ ~ 10⁸⁰ 年（宇宙寿命的 10⁷⁰ 倍）|

**Π 的角色**：蒸发时间 τ ∝ M³ ∝ 1/T³ ∝ Π³。所以 Π 越大，蒸发越慢。

### 2. 极端 Kerr（a = M）

当 a = M（最大旋转）：

```
r₊ = M, r₋ = 0
T = ħc³ M / [4Πk_B G M (M² + M²)] = ħc³ / (8ΠGMk_B)
```

**与 Schwarzschild 相同！** 旋转不改变 Hawking 温度（在 extremal Kerr 极限下）。

### 3. 零温极限（a → M，但 r₊ → r₋）

当 a → M，内视界和外视界合并：

```
r₊ - r₋ → 0
T → 0
```

**Extremal Kerr 黑洞（a = M）的 Hawking 温度 = 0**。这是经典广义相对论的预言（量子修正可能改变）。

## 实际影响

### 1. 原初黑洞（Primordial Black Holes, PBHs）

**形成机制**：早期宇宙密度涨落 → 原生黑洞（质量 ~ 10¹² kg）

**Hawking 蒸发**：
- T ~ 10⁸ K → 发射 γ 射线、正电子、负电子
- 如果 PBH 正在蒸发，应该能探测到 γ 射线背景

**Π 的角色**：
- T ∝ 1/Π → Π 的微小变化会显著改变蒸发速率
- 如果 Π 更大，PBH 蒸发更慢 → 更长寿命

### 2. 黑洞热力学

Hawking 温度满足 **热力学第一定律**：

```
dM = T dS + Ω dJ + Φ dQ
```

其中：
- S = A/(4Għ) = (Πr₊²)/(Għ) （黑洞熵）
- Ω = a/(2Mr₊) （角速度）
- J = aM （角动量）
- Q = 电荷

**Π 的角色**：熵 S ∝ Π，温度 T ∝ 1/Π。所以 Π 连接了熵和温度。

### 3. 黑洞信息悖论

Hawking 辐射是**热谱**（无信息）。这导致信息悖论。

**Page 时间**（蒸发到一半的时间）：

```
t_Page ~ (M_initial³ / M_Plank³) · t_Plank
```

**Π 的角色**：Page 时间 ∝ M³ ∝ 1/T³ ∝ Π³。所以 Π 决定了信息释放的时间尺度。
