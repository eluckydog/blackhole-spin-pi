# 维度一：视界面积 — Π 作为几何

> 任何旋转黑洞的视界面积都正比于 Π。这不是巧合，这是 U(1) 对称性的几何结果。

---

## Kerr 度规与视界

Kerr 度规描述旋转黑洞（Spin 参数 a = J/M²）：

```
ds² = - (1 - 2Mr/Σ) dt² - (4Mar sin²θ/Σ) dt dφ + (Σ/Δ) dr² + Σ dθ² + (r²+a²+2Ma²r sin²θ/Σ) sin²θ dφ²

其中：
Σ = r² + a² cos²θ
Δ = r² - 2Mr + a²
```

**事件视界** 在 Δ = 0 处：

```
r₊ = M + √(M² - a²)  (外视界)
r₋ = M - √(M² - a²)  (内视界，Cauchy 视界)
```

---

## 视界面积公式

Kerr 黑洞的视界面积：

```
A = 4π(r₊² + a²) = 8πMr₊
```

**Π 的角色**：Π 定义了几何面积。没有 Π，面积公式会是 `4(r₊² + a²)` —— 这是错的（量纲不对，且数值差 3.14 倍）。

### 推导（简略）

视界是一个 2-球（轴向压缩的球），度规诱导度量：

```
dA² = Σ dθ² + (r₊² + a²)² sin²θ / Σ dφ²
```

积分：

```
A = ∫₀^π dθ ∫₀^{2π} dφ √[Σ sin²θ (r₊² + a²)² / Σ]
  = 2π (r₊² + a²) ∫₀^π sinθ dθ
  = 4π (r₊² + a²)
  = 8πMr₊
```

**Π 来自哪里？** 来自方位角 φ 的积分范围 [0, 2π) —— 这是 U(1) 对称性的直接结果。

## 关键阈值

### 1. 极端 Kerr（a = M）

当 a = M（最大旋转）：

```
r₊ = M + √(M² - M²) = M
A = 4π(M² + M²) = 8πM²
```

面积非零！（与 Schwarzschild 不同，Schwarzschild 当 M→0 时 A→0）

### 2. Schwarzschild（a = 0）

当 a = 0（无旋转）：

```
r₊ = 2M
A = 4π(4M² + 0) = 16πM²
```

这是 Schwarzschild 黑洞的视界面积。

### 3. 面积定理（Hawking 面积定理）

**任何经典过程中，总视界面积永不减少**：

```
dA/dt ≥ 0
```

**Π 的角色**：面积定理中的 A 正比于 Π。所以 Π 也参与了这个热力学定律。

## 实际影响

### 1. 黑洞熵（Bekenstein-Hawking 公式）

```
S = A / (4Għ) = 2πMr₊ / (Għ)
```

**Π 的角色**：熵正比于 Π。没有 Π，熵的量纲不对（面积/作用量 = 无量纲？不对）。

### 2. 黑洞合并（引力波事件）

两个黑洞合并，最终面积满足：

```
A_final ≥ A₁ + A₂
```

LIGO/Virgo 测量到 GW150914（双黑洞合并），最终面积 ~ 10⁸ km²，熵 ~ 10⁷⁷ k_B。

**Π 的角色**：面积计算需要 Π，所以引力波波形模型也需要 Π。

### 3. 黑洞压缩（Black Hole Compression）

如果黑洞旋转极快（a → M），视界在赤道处变平：

```
极轴半径: r_pole = r₊
赤道半径: r_eq = r₊ / √(1 - a²/M²)  (无穷大当 a→M)
```

**Π 的角色**：形状因子涉及 Π（面积 = 4Πr² 只适用于球，Kerr 不是球对称）。
